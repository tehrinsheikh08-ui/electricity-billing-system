# Electricity Billing System

A simple console-based Electricity Billing System written in C.

## Modules

### 1. Consumer Management
- Add a new consumer (ID, name, address, units consumed)
- Display all consumers
- Search for a consumer by ID

### 2. Bill Generation
- Calculates the bill at Rs. 2 per unit
- Generates a formatted electricity bill for a consumer using their ID

## How to Run

1. Install a C compiler (GCC)
2. Compile: gcc main.c -o main
3. Run: ./main (Mac/Linux) or .\main.exe (Windows)

## Menu Options

1. Add Consumer
2. Display All Consumers
3. Search Consumer
4. Generate Electricity Bill
5. Exit
